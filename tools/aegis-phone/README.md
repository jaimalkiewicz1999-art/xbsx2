# AegisSX2 phone settings preview

Open `index.html` in a phone browser, select the current `PCSX2.ini`, adjust the options, and download the edited copy. The page works offline. It keeps all unrelated INI keys and never reads `secrets.ini`.

This is a file-based first step toward phone configuration. The Xbox build does not yet expose a paired live settings endpoint, so edits must be transferred to the same settings location through a method available on the user's Xbox setup. Close AegisSX2 before replacing its settings file. Do not replace `secrets.ini`.

Upscaling changes render resolution, which can affect performance. FPS patches are game-specific and remain in AegisSX2's in-app patch controls.
